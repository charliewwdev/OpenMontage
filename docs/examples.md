# One-line idea examples

Paste one of these into the studio idea box (or Agent). Each line is a starting prompt — expect an editable script first, then characters / scenes / props, then storyboard shots you can regenerate per clip.

Also available in Chinese below each English line.

---

## Short drama（短剧）

1. **EN:** 3-episode revenge short drama, 9:16, cold open with a betrayal reveal in the first 3 seconds, female lead, modern city night.  
   **ZH:** 3 集复仇短剧，竖屏 9:16，前 3 秒冷开场揭露背叛，女主，现代都市夜景。  
   **Expect:** Episode outline + character bible; stills for lead/antagonist; shot list with Seedance-ready prompts.

2. **EN:** 5-episode office romance, rivals-to-lovers, each episode under 90 seconds, cliffhanger end every episode.  
   **ZH:** 5 集职场甜宠，欢喜冤家，每集 90 秒内，集末留悬念。  
   **Expect:** Multi-episode script beats; two consistent character looks; light comedy dialogue for TTS.

3. **EN:** Time-loop thriller short drama: same morning, three loops, twist that the loop is a job interview.  
   **ZH:** 时间循环惊悚短剧：同一天早晨循环三次，反转是这场循环其实是一场面试。  
   **Expect:** Repeated scene assets with small visual deltas; escalating dialogue per loop.

4. **EN:** Wuxia revenge in 4 vertical episodes, rain duel in episode 1, mentor betrayal in episode 3.  
   **ZH:** 4 集竖屏武侠复仇，第 1 集雨夜对决，第 3 集师父反水。  
   **Expect:** Costume/prop references (sword, rain street); high-contrast night stills; fight-shot storyboard.

5. **EN:** Family secret short drama, dinner table argument as cold open, DNA test result as mid-series turn.  
   **ZH:** 家族秘密短剧，餐桌争吵冷开场，中期反转是 DNA 鉴定结果。  
   **Expect:** Indoor dining scene lock; 3–4 speaking roles; dialogue-heavy dubbing pass.

## Viral short video（爆款短视频）

1. **EN:** 30-second “day in the life of a solo founder”, punchy captions, 3 scene cuts, CTA to follow.  
   **ZH:** 30 秒「独立创始人的一天」，强字幕，3 个场景切换，结尾关注 CTA。  
   **Expect:** Short script with hook → montage → CTA; fewer characters; fast shot cadence.

2. **EN:** Myth-busting tech tip video: wrong way vs right way, on-screen labels, under 45 seconds.  
   **ZH:** 科技辟谣短视频：错误做法 vs 正确做法，屏幕标签，45 秒内。  
   **Expect:** Two visual variants of the same desk setup; caption-led edit.

3. **EN:** Street-food ASMR-ish vertical short: sizzle open, three close-ups, price reveal at the end.  
   **ZH:** 街头美食竖屏：开场滋滋声画面，三个特写，结尾价格反转。  
   **Expect:** Prop/food close-ups; minimal dialogue; strong end card.

4. **EN:** “POV: you finally ship v1” motivational short, neon night city, 20 seconds.  
   **ZH:** POV：终于上线 v1，霓虹夜城，20 秒励志短片。  
   **Expect:** One protagonist still + city night scene; sparse VO.

5. **EN:** Before/after room makeover in 25 seconds, left-right wipe, upbeat music bed.  
   **ZH:** 25 秒房间改造前后对比，左右擦除转场，轻快 BGM。  
   **Expect:** Two scene stills (messy / clean); wipe-friendly storyboard.

## Product / e-commerce ad（带货）

Use the product-ad shape: **pain point → close-ups → benefit captions → CTA**.

1. **EN:** Wireless earbuds ad, 20s, pain = tangled commute cables, close-ups of case + fit, CTA “Shop now”.  
   **ZH:** 无线耳机 20 秒广告：痛点是通勤耳机线缠绕，耳机盒与佩戴特写，CTA「立即购买」。  
   **Expect:** Product prop sheet; 4–6 shots; benefit captions burned or overlaid in edit.

2. **EN:** Skincare serum vertical ad: dry skin pain, texture close-up, 3 benefit bullets, “Link in bio”.  
   **ZH:** 精华液竖屏广告：干燥肌痛点 → 质地特写 → 三条功效字幕 →「主页链接」。  
   **Expect:** Bottle hero still; macro texture shot; short VO script.

3. **EN:** Portable blender for office lunch, problem = no time to cook, demo pour shot, 15s hard cut CTA.  
   **ZH:** 办公便携榨汁杯：没时间做饭 → 倒出特写演示 → 15 秒硬切 CTA。  
   **Expect:** Desk scene + product prop; demo-oriented storyboard.

4. **EN:** Smartwatch fitness ad: missed workout guilt → night run tracking UI → “Start free trial”.  
   **ZH:** 智能手表运动广告：错过训练的内疚 → 夜跑轨迹 UI →「开始免费试用」。  
   **Expect:** Wearable close-up; runner night scene; UI-friendly captions.

5. **EN:** Mechanical keyboard unboxing energy, RGB glow, typing ASMR cutaways, CTA discount code.  
   **ZH:** 机械键盘开箱感，RGB 光效，敲击特写，结尾优惠码 CTA。  
   **Expect:** Product-centric props; dark desk lighting; caption for discount code.

## Tips

- Keep aspect ratio in the line (`9:16` / `16:9`) when it matters.
- Name the genre + episode count for short drama; name the seconds for viral / ads.
- After generation, edit one stage at a time — regenerate a single character or shot instead of restarting.
