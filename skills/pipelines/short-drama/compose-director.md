# Compose Director — Short Drama

## Process

1. Compose via `video_compose` / HyperFrames per locked runtime.
2. Run `drama_visual_qa` on the master; attach `drama_qa_report`.
3. Compute `production_metrics` (usable_rate, cost_per_minute, rework_rate, human_intervention_count).
4. Produce `final_review`.

## Output

`render_report`, `final_review`, `drama_qa_report`, `production_metrics`.
