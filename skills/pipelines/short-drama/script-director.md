# Script Director — Short Drama

## Process

1. Write dialogue-led script; keep narration sparse.
2. Fill `speakers` and `dialogue_beats` on the script artifact.
3. Ensure hook in first 3s and a cliffhanger for short-form.
4. Map beats to future scenes (label sections by scene intent).

## Output

Schema-valid `script` with speakers/dialogue_beats for dialogue-led concepts.
