# 竖屏短剧分镜（对齐 SceneMixer · 整集 3–6 分钟）

参考 SceneMixer 样片与教学（如 showcase《染血玉令》、[一镜怎么写](https://scenemixer.cn/guides/yi-jing-zenme-xie/)）：

- **资产库先锁**：角色 / 场景 / 道具设定图；脸靠图，不靠提示词反复描五官
- **整集硬目标**：
  - 分镜数 **12–30**（默认目标 **18–24**；禁止少于 12）
  - 成片总时长 **180–360 秒（3–6 分钟）**（各镜 `duration` 之和）
  - 单镜多数 **6–12 秒**（对白镜可到 10–12s；纯反应可 5–6s）
- **一镜一个节拍**：推信 / 横剑 / 放匣 / 一句台词——两拍就拆两镜
- **音画同生**：对白写进镜头，说完写「闭唇」；听的人写「闭唇、唇部未动」
- **配乐单独一层**（导出时垫 BGM），不要用后期解说盖掉口型

## 整集编排（必须铺满 3–6 分钟）

按「片段」思维写，但输出仍是扁平 `shots[]`（每个 shot 对应一段可生成视频）：

1. **建立**（2–4 镜）：入画 / 空镜 / 环境，无或短对白
2. **冲突升级**（反复循环，占全集体量一半以上）：
   - 动作镜 → 对白镜（闭唇）→ 反应镜（无对白）→ 道具/证据镜
3. **中段反转**（2–4 镜）：信息差揭开或威胁加码
4. **高潮对峙**（3–6 镜）：轴线稳定的正反打
5. **悬念终态**（1–2 镜）：定格 / 背影 / 短信亮屏，留 1–2s 静止感

**自检（输出前必算）**

- `shots.length` ∈ [12, 30]
- `sum(duration)` ∈ [180, 360]
- 若时长不够：加反应镜、走位镜、道具特写，**禁止**把单镜拉成空洞长镜凑数
- 若镜数将超 30：合并同机位连续微动作，保留节拍清晰的镜

## 一镜标准形状（按观众注意顺序写）

```text
【分镜N】Xs:
承接分镜N-1（首镜写「起始：」）。
景别+机位。@角色A 在画面左/中，@角色B 在画面右；谁面朝谁。
发生的那一件可见事（手/脸/身体/物件），情绪用「由X转Y」括注。
有台词则：@名字（语气括注）：台词。说完最后一个字闭唇，再跟一个微动作。
听的人：闭唇、唇部未动 / 抿唇静默。
光源写方向与种类。无对白则末尾写「无对白」。
环境音：……（可写在段尾共用）。
```

### 可照抄的三类镜

**反应（无对白）**

```text
【分镜4】5s: 特写。画面内仅 @朱尔斯。他低头看信，下颌绷紧。无对白。环境音：雨。
```

**带走动的台词**

```text
【分镜5】8s: 中景手持。@玛拉 起身走到窗前，背对他。@玛拉（轻声，不回头）：上面写什么我早知道。说完闭唇。
```

**对白镜（口型+听者）——对齐《染血玉令》**

```text
【分镜3】6s: 承接分镜2。中近景固定，画面主体为 @林晚，3/4 侧身朝画面右侧；右侧对手仅见虚化肩线与手臂。
@林晚 一手撑膝抬头、下颌绷紧（由喘息转硬顶）；唇部跟「我去苍梧」字音同步，重音在「取剑」。
@林晚（撑膝抬头，字字咬实，倔强压怒）：我去苍梧岭，是替宗门取剑。
说完最后一个字她闭唇，撑膝的手指攥紧半分。听的人抿唇静默。冷青天光自左上方斜下。
```

## 硬规则

- 画幅按项目 `ratio`（默认 9:16）。
- **一镜只一个可见动作**；换景别 = 新镜。
- **一镜最多一句对白、一个说话人**；对白与反应拆相邻两镜。
- `dialogue` 字段：`角色名：原话`（不要「X说：」解说腔）。
- `prompt` 用上面「一镜标准形状」写成连贯自然语言；用 `@角色` / `@道具` / `@场景` 点名本集资产。
- 台词秒数：中文约 **每秒 4–5 字**；15 字台词至少 4–5s，再加动作则更长。
- 反应镜 **5–6s**；对白+微动作 **6–10s**；走动 **8–12s**。`duration` 整数，范围 **5–12**。
- 光线写**光源**：「冷青天光自云海方向斜照」；不写「光打亮她的额头」。
- 连续对手戏写 **轴线同一侧**、**承接上一镜**，避免跳轴。
- 说完台词必须写 **闭唇**；否则口型拖到镜尾。
- **禁止** `8K` / `大师级` / `体积光` / `best quality` 等旧触发词。
- 画面外的人**不要 @ 点名**（只写「视线朝画面右」），避免换脸。
- **禁止**输出少于 12 镜或总时长不足 180 秒的「样片级」短板分镜。

## 输出 JSON

```json
{
  "shots": [
    {
      "shotOrder": 1,
      "sceneName": "场景名",
      "characters": ["角色名"],
      "action": "一个可见动作 + 由X转Y",
      "dialogue": "角色名：原话（或空）",
      "prompt": "按【分镜N】Xs: 标准形状写的完整提示词，含 @引用、闭唇、听者、光源、环境音",
      "duration": 8
    }
  ],
  "totals": {
    "shotCount": 20,
    "durationSec": 240
  }
}
```

只输出 JSON。镜数与总时长必须落在硬目标内；宁可多几个清晰节拍镜，也不要 6 镜「预告片」。
