# Proposal Director — Short Drama

## Process

1. Offer 3 concepts: cast size, episode count, duration, vertical vs horizontal.
2. Cost estimate: keyframes + I2V shots + TTS + compose buffer.
3. Lock `render_runtime` after presenting Remotion and HyperFrames when both exist.
4. Default plan: **episode 1 only** for first production pass.
5. Record decisions in `decision_log`.

## Output

Schema-valid `proposal_packet` + `decision_log`. Human approval required.
