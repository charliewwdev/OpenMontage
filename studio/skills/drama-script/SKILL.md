# 分集剧本生成（对齐 SceneMixer 信息密度）

根据创作需求、题材、画幅、视觉风格生成**可直接拆成 12–30 镜、成片 3–6 分钟**的短剧分集剧本，并同步角色/场景/道具档案。

## 时长与密度（硬目标）

- 严格生成用户指定的集数（1–10）。
- **每一集**必须支撑后续拆镜：
  - 目标成片 **180–360 秒（3–6 分钟）**
  - 对应分镜 **12–30 个**（多数镜 6–12 秒）
- 每集写 **12–20 场**（场号 `[1]` 起递增；场次之间空一行）。场次过少会导致拆镜灌水。
- 每场必须写清：**地点、时间、天气/光线、人物站位、可见动作、有效对白、本场钩子**。
- 禁止空场：无动作无对白的「过场说明」不要单独成场，并入相邻场。
- 竖屏优先人物关系、近景冲突、反应镜；横屏可增加调度与空间层次。

## 场次写法（可拍，不是提纲）

每场建议结构：

```text
[N]
地点：具体场景名（与资产库场景名一致）
时间：日/夜/清晨…；天气或光源一句
人物：出场角色（含龙套）
站位：谁在画面左/右/中，谁面朝谁（便于后续保轴线）
动作：可见肢体与道具交互（由情绪 A 转 B）
对白：口语化；一句一行「角色名：台词」；关键句标注语气
钩子：本场结尾必须留下信息差/威胁/反转之一
```

- 对白密度：每集至少 **8–15 句有效对白**（可分布在多场），避免整集只有 3–4 句。
- 动作与对白交错：冲突动作场与对白/反应场交替，方便拆成「动作镜 → 对白镜 → 反应镜」。
- 道具要在正文里**被看见、被使用**（递、摔、藏、亮出），不要只出现在道具表。

## 资产库（本集可引用）

- 角色：主角 + 对手 + 必要配角/龙套；可多造型；标记出场集数。
- 场景：空镜可拍的空间描述（无人物），名称稳定，供分镜 `@场景`。
- 道具：外形材质 + 剧情功能；跨集关键物必建档。

## 输出 JSON

```json
{
  "summary": {
    "title": "片名",
    "synopsis": "梗概",
    "genre": "题材",
    "protagonist": "",
    "background": "",
    "setting": "",
    "oneSentence": ""
  },
  "episodes": [
    {
      "episodeNumber": 1,
      "title": "第1集标题",
      "content": "带场号的剧本正文（12–20 场，可支撑 3–6 分钟 / 12–30 镜）",
      "targetDurationSec": 240,
      "targetShotCount": 20
    }
  ],
  "characters": [
    {
      "name": "角色名",
      "role": "protagonist|antagonist|supporting",
      "gender": "unknown",
      "introduction": "",
      "voiceDescription": "",
      "looks": [
        { "name": "默认形象", "description": "外貌服装光线", "episodes": [1] }
      ]
    }
  ],
  "scenes": [
    { "name": "场景名", "description": "空间光线陈设，无人物", "episodes": [1] }
  ],
  "props": [
    { "name": "道具名", "category": "item", "description": "外形材质与用法", "episodes": [1] }
  ]
}
```

只输出一个完整 JSON 对象。宁可场次密、动作清，也不要短提纲式「一页剧情」。
