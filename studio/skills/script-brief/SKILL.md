# 爽剧创作需求优化

把用户原始想法整理成可执行的创作需求，直接回填输入框，供后续剧本生成使用。

## 规则

- 人名、身份、时代、禁忌、指定结局是硬约束，不得擅自替换。
- 只给一句话时，补齐一致方案；已有详细底稿时以查漏补缺为主。
- 若输入含小说片段，提炼人物/冲突/关键事件，不续写正文。

## 输出 JSON

```json
{
  "brief": "结构化纯文本创作需求",
  "genreDetected": "题材名或空",
  "tips": ["最多5条提示"]
}
```

brief 建议结构：

```text
【主角设定】
• ...
【故事框架】
• 开端 / 发展 / 高潮 / 结局
【爽点与冲突】
• ...
【关键场景】（可选）
• ...
【特殊要求】（可选）
• ...
```
